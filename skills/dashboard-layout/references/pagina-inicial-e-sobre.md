# Página inicial e página Sobre

Padrão sugerido pelo autor (convenção, não regra universal).

## Página de abertura
- A página **Início** é a página de abertura do relatório: grave-a como
  `landingPageName`. Procure o nome da propriedade em um relatório já salvo pelo
  Desktop antes de editar, e confirme ao reabrir que o relatório abre nela.
- `activePageName` não deve apontar para página oculta (ver
  `tmdl-pbir/references/edicao-por-script-e-desktop.md`).

## Versão e data na página Sobre
- A página **Sobre** informa a **versão** e a **data** da última atualização do
  relatório.
- **Atualize os dois a cada leva de edições** (feita por script ou à mão), no
  mesmo commit. Relatório com versão velha na página Sobre faz o leitor duvidar
  dos números.
- Se a versão vem de uma medida ou de um texto fixo, registre onde está no
  dicionário do modelo, para a próxima leva não esquecer.
